What a row shows

  • One time per row, always top right. Start shows the departure, stops and destination the arrival, so the right edge reads as a schedule.
  • The battery is Material's horizontal battery frame. It shows the level on arrival in the nearest of its steps, in the neutral grey of the secondary text. Beside it stand the level on arrival and the level you leave with, "18% → 67%", then the charging power.
  • Charging time sits under the arrival time. The right edge reads as when you arrive and how long you stay.
  • Start and destination carry a location pin. The start row leads with its address instead of the word "Start". Below it sits the battery with the charge level, in the same place as on the stop cards. On the trip sheet the start address and both levels have a pencil; on the active route nothing is editable.
  • Markers in one colour. The numbered circles and both pins use the app's primary colour instead of one colour per operator.
  • Same rows on the active route. The committed trip's page keeps its summary card with "Neu planen" and "Navigieren beenden" and lists the stops with the same cards.
  • Not on the card: departure time. It belongs to the stop detail.

Leg distances, place names and the start address are placeholders. Planning from an address other than the current position does not exist in the app today, so an editable start address is a new function, not only a new row. The plan already holds what the stop cards and the destination row show (position along the route, charge level on arrival, charging minutes, site name, destination address). The start is only a position today, so its address would have to be looked up.
